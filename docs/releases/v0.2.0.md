# RelayBond v0.2.0 — Verified payer and live evidence console

Released: September 15, 2026

## Protocol integrity

- Derives the buyer from the facilitator-verified EIP-3009 authorization.
- Revalidates network, token, amount and payee before signing delivery evidence.
- Normalizes paid request input before hashing it into the Delivery Receipt.
- Requires a decoded final-success settlement receipt before writing LIVE paid evidence.
- Adds guarded `accepted`, `empty` and `stale` paid scenarios; breach scenarios are disabled unless explicitly enabled.
- Adds an evidence-derived, replay-safe live rebate executor with an explicit confirmation gate.

## Public integration

- Adds `GET /v1/service/promise` and the missing public `POST /v1/verify` endpoint.
- Adds CORS for external Agent and SDK integrations.
- Ships an importable TypeScript SDK build with declarations and package exports.
- Updates OpenAPI and the OKX AI / A2MCP listing package.

## Judge experience

- Adds a real browser-side EIP-712 signer recovery bundle.
- Adds a live HTTP 402 probe that never signs or pays.
- Publishes contract, bond, Service Promise and Agentic Wallet funding evidence.
- Clearly separates LIVE / TESTNET evidence from the deterministic local breach lab.

## Verification

- 19 unit tests.
- 4 Solidity contract tests.
- TypeScript typecheck, browser bundle, deterministic evidence verification and package dry-run all pass.

After release preparation, a first 0.01 Testnet USD₮0 Agentic Wallet payment settled successfully in transaction `0x2a9b32e353a93179f6f811b687051382ce9de782c9fd4f3bc3058b0c9d2bd125`. Its merchant delivery body was not persisted because the initial facilitator receipt was still pending. The runner now follows that transaction to the chain and verifies the exact token transfer before saving evidence. A complete `ACCEPTED` delivery and the real onchain breach rebate remain pending.
