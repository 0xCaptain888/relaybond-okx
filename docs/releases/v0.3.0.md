# RelayBond v0.3.0 — Double-pay-free Agent recovery

Released as a pre-build prototype on September 15, 2026. This release predates the listed September 17 Remote Build start and is disclosed accordingly.

## Product upgrade

- Repositions RelayBond from refund-only warranties to a reliability clearing layer.
- Adds a Bonded Provider Registry ranked by SLA, capital coverage and verified history.
- Adds deterministic `PAID → BREACH → REBATED_TO_RECOVERY → BACKUP_DELIVERED → RECOVERED` evidence.
- Adds a verifier-signed EIP-712 Continuity Receipt.
- Proves the buyer pays once while the primary provider bond funds the backup.

## Contract and integration

- Adds `RecoveryBondVaultV2`, with verifier authorization, provider separation and replay protection.
- Adds `/v1/providers` and `/v1/recovery/demo` read-only endpoints.
- Extends the TypeScript SDK and browser verifier.
- Adds unit and contract tests for ranking, recovery economics and settlement invariants.
