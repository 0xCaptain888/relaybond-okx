# RelayBond v0.4.0-rc.3

Date: September 17, 2026

## Judge experience

- Added a prominent one-click **Run 60-second Judge Proof** entry point.
- Verifies the live OKX x402 boundary without signing a payment.
- Re-checks the recorded paid Primary `BREACH` and independent Backup `ACCEPTED` result.
- Recovers the live verifier signatures and portable evidence integrity in the browser.
- Fetches the public final settlement and requires exactly 7/7 passing X Layer checks.
- Confirms that the buyer balance remained unchanged during recovery.
- Fails closed and never shows a success verdict when any proof is missing.
- Works from the Vercel Demo and uses the Vercel API when opened from the GitHub Pages mirror.

## Submission assets

- Expanded `docs/submission-copy.md` into a complete submission package.
- Added a timed 2:45 English demo script and recording checklist.
- Preserved the distinction between a read-only proof replay and a newly broadcast transaction.

HTTP 402 VERIFIED
→ PAID PRIMARY BREACH
